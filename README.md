### Case studies — Tick, October 2026

- **Approvals a person can judge.** What a person must see before AI agents act: what may change, what may be spent, what comes back and how to stop. Building it showed that a plan made in the conversation has no spending limit and no way to set one, which became the next decision. *Shipped in Tick 0.5.97.*
- **A dashboard that opens on what needs you.** The three questions a first screen answers — what needs you, what is running, what it is costing — read across every running run, with nothing that fails to load ever passed off as quiet. *Shipped in Tick 0.5.97.*

Researched, prototyped and built by AI coding agents working in Tick; the decisions were mine.
